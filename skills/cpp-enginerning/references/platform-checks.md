# 可选平台检查

仅在本次任务已确认涉及对应平台时读取。项目事实来自当前仓库，不从其他项目或会话继承。


对已确认为实时的路径，遵守记录的分配、阻塞、队列容量、工作量和执行期限上界。
避免把设备等待、网络等待或不可控回调放入该路径；不能无证据将普通业务线程称为硬实时。
检查控制任务的 deadline、时钟域、坐标系、单位、饱和/限位、消息新鲜度及失联策略。
变更限位或安全行为必须处于明确授权和验证范围，默认只做离线/仿真检查。

ROS 2 适配要检查现有 QoS、回调组、executor、消息拥有关系和关闭顺序。
DMA-BUF/共享内存边界要说明句柄作用域、拥有/借用、同步与回收；不能把一个进程内的句柄值
直接当作跨进程有效所有权。检查设备仍访问时是否可能释放、重用或解除映射。

这些是风险入口，不要求所有普通 C++ 项目引入 ROS 2、实时系统或 DMA 抽象。
